# Employee Profile Generator

## Description

This project is part of the freeCodeCamp Python Certification v9 curriculum. It focuses on creating an employee profile using Python variables and string manipulation.

## Concepts

- Variables and data types
- String concatenation
- String methods
- String formatting with f-strings
- String indexing and slicing
- Working with employee information

## Goal

Practice Python fundamentals by combining and formatting employee data to generate a readable employee profile.
