# Travel Weather Planner

## Description

This project is part of the freeCodeCamp Python Certification v9 curriculum. It focuses on using weather information and travel preferences to help plan a trip.

## Concepts

- Variables and data types
- Strings and string formatting
- Booleans and conditionals
- Comparison operators
- Conditional logic
- Decision-making based on weather conditions

## Goal

Practice Python fundamentals by evaluating weather conditions and providing suitable travel recommendations.
