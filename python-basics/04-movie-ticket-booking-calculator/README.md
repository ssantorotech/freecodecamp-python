# Movie Ticket Booking Calculator

## Description

This project is part of the freeCodeCamp Python Certification v9 curriculum. It focuses on calculating movie ticket prices based on booking details and applicable conditions.

## Concepts

- Variables and data types
- Arithmetic operators
- Booleans and conditionals
- Comparison operators
- Conditional logic
- Calculations and output formatting

## Goal

Practice Python conditionals and arithmetic by calculating ticket prices according to different booking conditions.
