Python Basics


Foundational Python exercises and notes completed while following the freeCodeCamp Python V9 curriculum.
This directory collects small learning exercises from the Python Basics section. The aim is to build a strong foundation in Python before moving on to more advanced topics and developing larger applications in separate repositories.




Topics Covered
1. Introduction to Python
- What Python is
- Common uses of Python
- The role of Python in programming and automation
2. Variables and Data Types
- Assigning values to variables
- Naming variables
- Built-in types: str, bool, int, and float
- Inspecting values with type()
- Checking types with isinstance()
3. Strings
- Working with text values
- Using strings in output and simple text-based programs
4. Numbers and Mathematical Operations
- Working with numeric values
- Performing arithmetic operations
- Using calculations in practical programs
5. Booleans and Conditionals
- Boolean values: True and False
- Boolean expressions
- Making decisions with conditional logic
6. Functions and Scope
- Defining and calling functions
- Passing information to functions
- Returning results
- Understanding variable scope

- Python Basics Review — review of the concepts introduced in this section.
- Python Basics Quiz — knowledge check for the section.

Repository Scope
This repository is for learning notes, practice exercises, and smaller experiments related to Python. Larger standalone projects and complete applications will live in separate repositories, each with its own documentation and development history.
