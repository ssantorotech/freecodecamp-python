# Caesar Cipher

## Description

This project is part of the freeCodeCamp Python Certification v9 curriculum. It focuses on implementing a Caesar cipher to encrypt text by shifting letters of the alphabet by a specified number of positions.

## Concepts

- Functions
- Strings and string manipulation
- Variables and parameters
- Slicing and concatenation
- String methods
- `str.maketrans()`
- `str.translate()`
- Encryption algorithms

## Goal

Practice Python string manipulation and functions by implementing a Caesar cipher that transforms text using a specified shift value.
