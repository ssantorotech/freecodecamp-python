# Build an RPG Character

## Description

This project is part of the freeCodeCamp Python Certification v9 curriculum. It focuses on creating and validating a role-playing game (RPG) character using Python.

## Concepts

- Variables and data types
- Functions
- Parameters and return values
- Conditional statements
- Boolean logic
- Input validation
- Working with character attributes

## Goal

Practice Python fundamentals by creating an RPG character and validating its attributes according to specific rules.
