# Bill Splitter

## Description

This project is part of the freeCodeCamp Python Certification v9 curriculum. It focuses on calculating how to split a bill between multiple people.

## Concepts

- Variables and data types
- Numeric operations
- Arithmetic operators
- Working with numbers
- Calculating totals and individual shares
- Formatting output

## Goal

Practice Python arithmetic and calculations by dividing a bill fairly among a group of people.
